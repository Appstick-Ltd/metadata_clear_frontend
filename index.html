Flexible Modes

Choose How You Clean or Mask

Switch effortlessly between complete metadata removal and harmless cosmetic masking.

Wipe Mode

Total Erasure

Completely strips all EXIF, XMP, IPTC, GPS coordinates, camera serials, AI prompts, and author properties, leaving metadata segments empty.

  • Removes APP1/APP13, PNG text chunks, and WEBP EXIF blocks
  • Blanks PDF /Info dictionaries and DOCX core.xml author tags
  • Ideal for social sharing, messaging, and anonymous publishing

Ghost Masking

Cosmetic Spoof

Replaces real identifying metadata with normal, generic placeholder values when you want to preserve metadata structure for corporate tools.

  • Substitutes identifying author, device, and software headers safely
  • Prevents validation errors in strict enterprise intake pipelines
Transparency Note: Cosmetic replacement only — not verifiable cryptographic provenance.
