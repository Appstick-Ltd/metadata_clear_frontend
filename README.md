# Metadata Cleaner — Landing Page (`metadata_clear_frontend`)

Simple, responsive landing page for **Metadata Cleaner** (AI Metadata & Document Privacy Sanitizer) built with pure HTML5 and CSS3 (no frameworks, no JavaScript).

## Files

- `index.html` — Semantic landing page structure
- `styles.css` — Cyber-royal theme matched to the Metadata Cleaner app palette
- `assets/` — Web-optimized logo, favicon, and 3D app illustrations

## Preview Locally

Open `index.html` directly in any browser, or run a local static server:

```bash
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Customization

Replace the Android / iOS download `href` links in the `#download` section of `index.html` with your live Play Store, App Store, or APK release URLs.
